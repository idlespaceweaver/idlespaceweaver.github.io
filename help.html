Help

Saves, backups, purchases and phones.

Everything below is done from Settings inside the game. There is a fuller FAQ in there too, under Help.

I am moving to a new phone

Two ways. Doing both costs nothing.

  1. On the old phone, open Settings and tap Copy Recovery Code. Paste it somewhere safe: a note, an email to yourself, anywhere you will still have it tomorrow.
  2. Also tap Backup to File and keep the file.
  3. Install the game on the new phone, open Settings, tap Restore Save and paste the code or pick the file.

If cloud backup is switched on, the new phone may well offer to restore on its own when you first open the game.

What is a recovery code?

Your whole save, squeezed into a block of text you can copy and paste. It is the simplest way to move between phones and the only way to move between Android and iPhone.

Pasting is forgiving. Stray line breaks or spaces from an email or a chat message will not stop it working.

I lost my save

Try these in order, from Settings:

  1. Restore Save, then a backup file if you have one.
  2. Restore Save, then a recovery code if you saved one.
  3. If cloud backup was on, sign in to the cloud service and restore from there.

If none of those work, ask in the Discord. There is no guarantee, but it is worth asking.

Cloud backup

Switched on from Settings. On Android it uses Google Play Games, on iPhone and iPad it uses Game Center. Both keep the save in your own account, not on any server of mine.

The two clouds are entirely separate, so cloud backup will not carry a save from Android to iPhone or back. Use a recovery code for that.

My cloud save and my phone disagree

That happens when the game has been played on two devices without syncing in between. The game asks which one you want to keep. Pick carefully, because the other one is replaced.

I paid for something and it has gone

Open Settings and tap Restore purchases. As long as you are signed in to the same store account you bought with, it comes straight back. Reinstalling the game does not cost you anything you have already paid for.

What can I actually buy?

Two things and only two. A one-off upgrade that speeds up offline progress plus a tip jar that gives you nothing at all in the game.

There are no ads, no subscriptions, no loot boxes, no energy timers and nothing that lets anyone buy their way past you. That is not going to change.

Notifications are not arriving

Check the master switch in Settings first, then check your phone is not blocking the game at the system level. If the game is being blocked, Settings shows a warning row with a shortcut to fix it.

Nothing here helps

Ask in the Discord. It reaches me directly and I answer everything.

Still stuck?

Say so. I would much rather hear about a problem than have someone quietly give up.
